README — WK2022-23 analysis pipeline
===================================

Overview
--------
This repository contains the analysis pipeline used for the WK2022 and WK2023 Hudson/James Bay microbial community study.
The input files required to run the scripts can be downloaded either at https://osf.io/r32sy or
https://drive.google.com/drive/folders/19EClHmGsUfJGh99jsMc8_6NDhdeQkEp2.

The scripts assemble metadata and environmental data, clean and classify 16S/18S ASVs, identify plankton communities,
describe the plankton communities by focusing on their major groups and bioindicators, assess how diversity changes between the plankton communities,
elucidate the environments favoured by the plankton communities, produce publication‑ready figures to support my convictions, and produce NCBI submission tables.

Repository structure and its purpose
------------------------------------
Provided here on GitHub:
- 1_META.R        — compiling and cleaning oceanographic and other metadata for all DNA samples,
                    and computing derived variables (MLD, distance to coast)
- 2_TAX.R         — cleaning 16S taxonomy (SILVA), BLASTing 18S against PR2, selecting and organizing samples that have both 16S and 18S,
                    and building combined ASV table for non-rare taxa
- 3_CLUS.R        — clustering, identification of indicator taxa (indicspecies), heatmaps, TITAN
- 4_PLANKT.R      — Shannon diversity, and major taxonomic groups
- 5_INDIC.R       — bioindicators and cosmopolitans
- 6_MAPS.R        — maps: cluster map for this study, comparison to previous studies, biogeography of primary producers at surface
- 7_ENV.R         — dbRDA and environment statistics, MIMARKS & SRA outputs

Provided at https://osf.io/r32sy and https://drive.google.com/drive/folders/19EClHmGsUfJGh99jsMc8_6NDhdeQkEp2:
- CTD/            — input: raw oceanographic data from instruments (CTD, TSG, CastAway)
- DNA/            — input: raw results from 16S and 18S amplicon sequencing, and DNA sampling/analysis information
- EXT/            — input, but also generated by scripts: other supporting files, and RDS files to avoid computationally heavy reruns
- OUT/            — output: figures and tables generated by running the scripts

General recommendations
-----------------------
The best run order of the scripts is 1 → 2 → 3 → 4 → 5 → 6 → 7, but often you don't need to run all the previous script (read script headers for details).
Install R >= 4.6.1 and the required packages beforehand. Read the script headers and other comments to make the necessary configurations.
For example, if you are planning to BLAST 18S queries against PR2 yourself, you need to install BLAST+ on the path and allow an hour for BLAST to run.
Many scripts check for saved EXT/.rds to avoid re-running heavy steps like this. Use the provided seed (my birthday) to ensure reproducible randomness.
If you have questions or concerns, contact me at kazmiruz@myumanitoba.ca or the lab at cryomics@gmail.com. Good luck!
