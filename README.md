# WK2022-23 analysis pipeline

## Overview

This repository contains seven R scripts for analysing 16S and 18S rRNA gene amplicon sequencing data from water samples collected in southern Hudson Bay and James Bay during the WK2022 and WK2023 expeditions aboard the R/V William Kennedy (August 2022 and August 2023). The input data and supporting files required to run the scripts, together with the analysis outputs, are available as a 7z archive on [CanWIN](https://canwin-datahub.ad.umanitoba.ca/data/en/project/micb-wk2022-23). All files in the 7z archive are also available on [Google Drive](https://drive.google.com/drive/folders/19EClHmGsUfJGh99jsMc8_6NDhdeQkEp2), along with optional PR2 reference files and raw BLAST results.

## Repository structure and purpose

Provided on GitHub:

| Script | Purpose |
| --- | --- |
| `1W_META.R` | Compile CTD, thermosalinograph, CastAway, and DNA sampling data for all DNA samples, and calculate derived variables (mixed layer depth, distance to coast, geo_loc_name). |
| `2W_TAX.R` | Clean 16S taxonomy (SILVA), load PR2-based 18S assignments, select samples with both 16S and 18S data, and prepare original and non-rare ASV tables. |
| `3W_CLUS.R` | Cluster samples and ASVs, assess cluster stability, identify bioindicators and cosmopolitans, draw heatmaps and dendrograms, run TITAN, and check for flowthrough contamination. |
| `4W_PLANKT.R` | Calculate Shannon diversity, compare diversity among sample clusters, assess associations with environmental variables, and summarize major taxonomic groups. |
| `5W_INDIC.R` | Plot prevalent eukaryotic and prokaryotic bioindicators and cosmopolitans across sample clusters. |
| `6W_MAPS.R` | Draw maps of sample clusters, of stations sampled in this and previous studies, and of surface diatoms, non-diatom algae, Dinophyceae, and cyanobacteria. |
| `7W_ENV.R` | Assess environmental associations using dbRDA, plot T-S-depth and optical properties, compare environmental properties among sample clusters, and prepare NCBI submission metadata (MIMARKS and SRA). |

Provided in the data archive:

- `CTD/`: rosette and standalone CTD casts, thermosalinograph records, and CastAway profiles.
- `DNA/`: 16S/18S ASV tables, classifier results, DNA sampling and sequencing metadata, and the sequencing file list for the SRA table.
- `EXT/`: supporting files (Natural Earth shapefiles, bathymetry, HBC station list) and saved RDS results used or generated by the scripts.
- `OUT/`: figures, tables and submission files, organized by script.

## Setup and usage

Extract the four folders from the data archive on CanWIN or Google Drive into the directory containing the seven scripts, preserving all folder names and internal structures. Set the directory containing both the scripts and folders as the R working directory and run the scripts in sequence: **1W -> 2W -> 3W -> 4W -> 5W -> 6W -> 7W**. `2W_TAX.R` and `3W_CLUS.R` can also run independently because the required RDS files generated by earlier scripts are provided in `EXT/`; the remaining scripts use objects created by earlier scripts in the same R session (4W needs 2W and 3W; 5W needs 2W, 3W and 4W; 6W needs 3W; 7W needs 2W, 3W, 4W and 6W).

The scripts were run with **R 4.6.2** and **RStudio 2026.10.1.239** on 64-bit Windows. Install the packages loaded at the top of each script beforehand, including **dplyr >=1.2.0**; install `ComplexHeatmap` through Bioconductor. Using the provided saved results, all seven scripts take approximately **8 minutes** on a laptop with an **Intel Core i7-12700H** processor.

Saved 16S taxonomy, PR2-based 18S assignments, bioindicator results, TITAN results, and Shannon diversity estimates avoid repeating computationally intensive steps. The corresponding code is retained in commented blocks for reproducing the results during external review or rerunning the analysis if settings change. Rerunning BLAST also requires `Biostrings`, BLAST+ on the system PATH, and the optional PR2 reference files (`EXT/PR2/`) and raw BLAST results (`EXT/hits_pr2.rds`) from the Google Drive folder linked above.

Use the provided seeds for reproducibility.
